# SQL Manual QA Testing Project - E-Commerce Database

## Project Overview
This project demonstrates manual database testing skills for a simulated e-commerce application. It includes database schema design, test data generation, SQL verification queries, and bug reporting.

## Tools Used
* MySQL Server 26.10
* MySQL Workbench
* GitHub

## Project Structure
* `/database` - Contains the schema creation and cleanup scripts.
* `/test-cases` - Contains the manual test scenarios.
* `/bug-reports` - Contains documented defects found during testing, including SQL evidence.

## Key Skills Demonstrated
* Writing complex SQL queries (`JOINs`, `GROUP BY`, aggregate functions) to verify UI/API data against the database.
* Testing database constraints (`UNIQUE`, `CHECK`, `FOREIGN KEY`).
* Identifying data anomalies and writing professional, evidence-based bug reports.
* Executing cleanup scripts to ensure a repeatable testing environment.
